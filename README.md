# Zeiterfassung

Web-App (PWA) für Rufbereitschaft: Ruhezeit nach ArbZG/TV-Ärzte, Einsatzprotokoll, Brutto-Verdienst (TV-Ärzte/TdL), Statistik, Foto-Import.

Alle Daten bleiben im Browser des jeweiligen Geräts (kein Server, keine Übertragung). Auf dem iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm".
